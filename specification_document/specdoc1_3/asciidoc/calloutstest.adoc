:source-highlighter: pygments

This demonstrates listing captions with callouts in AsciiDoc.

== Listing with Caption and Callouts

[[protocol-example]]
.XML snippet showing SpectrumIdentificationProtocol. (1) The protocol element with its unique identifier. (2) Defines the search type. (3) CV terms *REQUIRED* for crosslinking searches.
[source,xml]
----
<AnalysisProtocolCollection>
    <SpectrumIdentificationProtocol id="SearchProtocol_1"> <!--1-->
        <SearchType>
            <cvParam accession="MS:1001083" name="ms-ms search"/> <!--2-->
        </SearchType>
        <AdditionalSearchParams>
            <cvParam accession="MS:1002494" name="crosslinking search"/> <!--3-->
            <cvParam accession="MS:1003330" name="noncovalently associated peptides search"/> <!--3-->
        </AdditionalSearchParams>
    </SpectrumIdentificationProtocol>
</AnalysisProtocolCollection>
----

== Combining Highlights and Callouts

[[search-params-example]]
.AdditionalSearchParams element. (1) Required for all crosslinking searches. (2) Should be present for proper FDR reporting.
[source,xml,highlight="3,4"]
----
<AdditionalSearchParams>
    <cvParam accession="MS:1001211" name="parent mass type mono"/>
    <cvParam accession="MS:1002494" name="crosslinking search"/> <!--1-->
    <cvParam accession="MS:1003343" name="FDR applied separately"/> <!--2-->
</AdditionalSearchParams>
----
