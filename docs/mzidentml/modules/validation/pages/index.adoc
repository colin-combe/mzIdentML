= Validation

Validating an mzIdentML file confirms that it conforms to the standard before you
share it, submit it to a repository, or load it into another tool. There are two
kinds of validation:

xref:schema-validation.adoc[Schema validation]:: Checks that the file is
  well-formed XML and matches the mzIdentML XML schema (XSD) for its version: the
  right elements and attributes, in the right places, with values of the right
  type. Any XML schema validator can do this.
xref:semantic-validator.adoc[Semantic validation]:: Checks what the schema cannot: that
  the required controlled-vocabulary (CV) terms are present and correctly used,
  and that the contents of the file are consistent. The semantic validator
  can run the schema validation as part of this.

A valid mzIdentML file passes both. Check the schema first, XSD errors are easier
to act on.

== Reporting Problems

If you think the semantic validator reports a problem wrongly, or a rule is
missing, please open an issue on the
https://github.com/HUPO-PSI/mzidentml-validator/issues[mzidentml-validator issue
tracker]. Report problems with the schema or the specification on
the https://github.com/HUPO-PSI/mzIdentML/issues[mzIdentML issue tracker].
