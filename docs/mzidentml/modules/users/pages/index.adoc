= mzIdentML for Users

This section is for people who *produce or consume* mzIdentML files — for example
when exporting search-engine results, submitting to a repository, or loading
identifications into an analysis tool.

== What is mzIdentML?

mzIdentML is a standard XML format for the results of identifying peptides and
proteins from mass spectra. Rather than every search engine using its own output
format, mzIdentML gives you one format that downstream tools, repositories, and
collaborators can all read.

A single mzIdentML file captures:

* the *input evidence* — spectra data files and the sequence database that was searched;
* the *search settings* — enzyme, tolerances, modifications, and scoring parameters;
* the *results* — the peptides identified, the spectra supporting them, and how those
  peptides map onto proteins.
