= Tools Supporting mzIdentML

This page lists proteomics software that reads (imports) or writes (exports)
mzIdentML, and the version of the format each tool supports. It is based on the
https://www.psidev.info/tools-implementing-mzidentml[HUPO-PSI list of tools
implementing mzIdentML].

Key to the columns:

I/E:: `I` = imports (reads) mzIdentML, `E` = exports (writes) mzIdentML.
License:: The software license, linked to where it is stated (a license file,
source header or package page). Commercial products link to the vendor's pricing
or quote page where one could be found. Licenses were checked in November 2026.

[NOTE]
====
Support details change as tools are released. Check each tool's own documentation
for its current mzIdentML support. If your tool is missing or a row is inaccurate,
please open an issue or pull request against the
https://github.com/HUPO-PSI/mzIdentML/blob/master/docs/mzidentml/modules/users/pages/tools.adoc[source of this page] in the mzIdentML repository.
====
