= mzIdentML Documentation Hub
:description: The official documentation for mzIdentML, the HUPO-PSI standard for reporting identifications from MS-based proteomics experiments.

mzIdentML is a https://psidev.info[HUPO Proteomics Standards Initiative (PSI)]
community standard for reporting the results of identifying peptides and proteins
from mass spectra. It provides a single, well-defined XML format for exporting
identification results from any search engine, and for importing them into
post-processing software and public databases.

== Highlights

[cols="1,3",frame=none,grid=none]
|===
|*Search-engine neutral*
|A common export and interchange format for identification results, independent of
the software that produced them.

|*Semantically enriched*
|Scores, parameters, and identifiers are anchored to controlled-vocabulary terms
from the https://www.ebi.ac.uk/ols4/ontologies/ms[PSI-MS ontology], so their meaning
is unambiguous across tools. Modifications are described using the
https://www.unimod.org/[Unimod] and
https://www.ebi.ac.uk/ols4/ontologies/xlmod[XLMOD] controlled vocabularies — see the
xref:developers:specification.adoc[specification] for details.

|*XSD-defined*
|The xref:developers:schema.adoc[XML Schema] formally defines every element and type,
enabling validation and automated tooling.

|*Crosslinking support*
|The xref:developers:crosslinking.adoc[crosslinking extension] describes how
crosslinking mass-spectrometry results — identifications based on multiple spectra —
are represented.

|*Repository-ready*
|mzIdentML is a PSI open standard format and as such receives Complete Submission status at
https://www.ebi.ac.uk/pride/markdownpage/submitdatapage[PRIDE].
|===
