== Key Concepts

mzIdentML is an XML format built on the shared HUPO-PSI object model. A few
principles recur throughout the specification:

* *Controlled vocabularies* — the meaning of scores, parameters, and identifiers
  is carried by CV terms (primarily the PSI-MS ontology) referenced by accession,
  rather than by fixed schema elements.
* *Separation of inputs and results* — spectra data files, search databases, and
  search settings are described once and referenced by the identification results.
* *Evidence-based structure* — peptides, their evidence in protein sequences, and
  the spectra that support them are linked explicitly, allowing results based on
  single or multiple spectra to be represented.

For the exact element definitions, see the xref:specification.adoc#model-in-xml-schema[Model in XML Schema]
section of the specification.
